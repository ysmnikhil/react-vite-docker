# Vite, Docker compose, Make file for the blog `How to use React or Vue with Vite and Docker`

This project contains the files related to the blog. To know more information about this please go to this blog [Dev.to](https://dev.to/ysmnikhil/how-to-build-with-react-or-vue-with-vite-and-docker-1a3l)

## How to use

Clone this repository to get the working copy of the project. This project depends on this utilities
- docker && docker compose (https://docs.docker.com/compose/install/#installation-scenarios)
- make or node (on host machine)

These will be the commands which you need to execute

If you have the `make` utility

```
// Only first time 
make first

// All the time
make start

```

If you have the `node` installed in the host. This will also run the docker commads

```
// Only first time 
npm run first

// All the time
npm run start

```
